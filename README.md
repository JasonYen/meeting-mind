MeetingMind — AI Meeting Notes That Never Leave Your Machine  Turn raw meeting recordings into clear, actionable notes — without sending a single byte of audio to the cloud.  Why  Remote teams lose hours every week re-watching recordings and rewriting notes. Cloud transcription services are expensive, leak private conversations to third parties, and lock your data behind a paywall. MeetingMind is a self-hosted, offline-first alternative that runs comfortably on a single laptop.  Features  Local transcription — faster-whisper (large-v3) runs on CPU or GPU; no API keys required  Speaker diarization — see who said what, with per-speaker word counts  AI summaries — summary, decisions, and action items via any OpenAI-compatible LLM endpoint (local or cloud, your choice)  Full-text search — search every transcript by keyword, speaker, or date  One-click export — Markdown, plain text, or JSON  How it works  Audio → faster-whisper transcription → pyannote speaker diarization
      → LLM summarization → structured Markdown notes in SQLite
